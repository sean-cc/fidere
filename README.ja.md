**常時稼働のアシスタント。不在の間もスケジュールどおりに仕事を片づけ、きちんと説明責任を果たします。**

Fidere は常時稼働のアシスタントです。ブラウザで話しかけ、質問し、思いついたことを預けておけます。あなたが不在のときは、スケジュールに沿って自分で仕事を進めます——監督なしでやり遂げ、結果を報告し、予算を超えたら自分で止まります。

Fidere はラテン語で **「信頼する」**。信頼は賢いモデルから生まれるものではありません。**やったことは検証でき、壊したものは元に戻せ、使ったお金は帳簿に残る**——この 3 つの地味な事実から生まれます。

![Fidere の会話画面](docs/screenshot-chat.jpg)

> **はじめての方へ** —— [クイックスタート](#クイックスタート)へ。クローンから約 5 分で動きます。

## 何が違うのか

### 自分で読み切れる小ささ

依存関係はひとつ、[pi coding agent](https://github.com/earendil-works/pi) だけです。Fidere はこれをライブラリとして使うので、`pi` CLI を自分で入れる必要はありません。フロントエンドフレームワークもバンドラーも CDN もなく、約 8,300 行の素の JS/CSS。データベースもメッセージキューも 2 つ目のサービスもなく、`node scripts/start.mjs` が実行経路のすべてです。ワークフローは覚える新しい言語ではなく、自分のディレクトリにある数個のファイルです。

### 同じ履歴に二度払わない

多くの自動化アシスタントは終わらない 1 つのセッションで、毎ターン全履歴をモデルに再送します。だから長く動かすほど遅く、高くなります。Fidere は逆です。

- **タスクごとにセッションを 1 つ立て、終わったら捨てる。** 引き継ぐのは数百語の要約だけで、会話ログ全体ではありません
- **判断が要らない工程はモデルに届かない。** 取得・変換・検証・通知はスクリプトで 0 トークン
- **安いモデルが判断し、高いモデルが手を動かす。** ルーティング・要約・整形は軽量モデル、難しい作業だけ格上げ
- **どのタスクにも予算の上限がある。** 超えたら即停止し、どこまで進んだか・いくら使ったかを台帳に書く

### 「完了」はモデルが言える言葉ではない

どのタスクにも実行可能な検証があり、終了コードが非ゼロなら未完了です。失敗は 3 段階でエスカレーションします。同じモデルで 1 回再試行 → より強いモデルで 1 回再試行 → 通知して停止。朝まで静かに回り続けることはありません。再実行で副作用が二重になることもありません（通知 2 通、注文 2 件は起きない）。各タスクのセッション・コマンド・コスト・結果はすべて残るので、失敗した実行は推測ではなく再生で確認できます。

### コストは実際のエンドポイントから来る

どの応答にもトークン使用量と、**実際に呼ばれたエンドポイント**のベンダー公式価格が付きます——DeepSeek のピーク／オフピーク価格、OpenRouter のトークン単価、Zhipu・Moonshot・Aliyun・Anthropic の公開ページ。固定の料金表ではありません。プロキシや自前のゲートウェイは、あなたが設定した `cost` で計算します。[エンドポイントごとの価格決定 →](docs/pricing.md)

### 高価なモデルを裏で勝手に差し替えない

新しいセッションは、あなたが見て変えられるモデルで始まります。再開したセッションでモデルを切り替えた場合は、会話の上に明示されます——代替モデルは数倍高くなることがあり、それはログファイルにだけ残す話ではありません。

## 機能

### 会話：思いついたことを何でも話す

- **途切れないセッション** —— 話し続けられます。コンテキストがいっぱいになると自動で要約され、どこまで話したかを忘れません。
- **開けるノート** —— アイデア・結論・ToDo は、開いて編集・検索できる markdown に。ブラックボックスではありません。
- **リアルタイム配信** —— 思考とツール呼び出しが流れ、応答が終わると折りたたまれ、応答ごとに開き直せます。
- **タイムライン移動** —— 右側のタイムラインで以前のプロンプトへワンクリックで戻れます。履歴を読んでいても最下部へ引き戻されません。
- **分岐して再送・復旧** —— 以前のメッセージを編集して新しいブランチで再送信。応答のコピー、拒否されたプロンプトの再試行、切断後の復旧も可能です。
- **セッションとモデルの管理** —— セッションの管理、モデルの切り替え、新しいセッションの既定モデル指定、画像やファイルの添付。
- **7 つの UI 言語** —— English、简体中文、繁體中文（台灣 / 香港）、日本語、한국어、Русский。
- **コマンドパレット** —— `/` ひとつでコマンド・モデル・スキル・プロンプトテンプレートを検索（[ショートカット](#キーボードショートカット)）。
- **Mac を眠らせない** —— 長いタスクの間だけ、任意で `caffeinate` を保持します。

### タスク：不在の間に処理する

- **スケジュール実行** —— N 分ごと、毎日決まった時刻、または平日のみ。
- **ハード予算** —— 静かに消費し続けるのではなく停止します。
- **実行可能な検証** —— モデルの「完了」は手がかりにすぎず、終了コードが結論です。
- **エスカレーションと通知** —— 同じモデル → より強力なモデル → 通知して停止。
- **発火時刻ごとに 1 回だけ** —— さらに安定した `FIDERE_RUN_KEY` を渡すので、外部副作用（注文・送信）を自分で重複排除できます。
- **台帳と毎日のレシート** —— 何が実行され、何が通り、いくらかかったか。
- **取りこぼしの補完** —— 再起動やスリープの後、逃したタスクを補い、レシートに遅れも記します。

### ワークフロー：1 ページの指示と数個のスクリプト

フローチャートも新しい構文もオーケストレーションエンジンも不要です。ワークフローは 1 つのディレクトリです。

```text
workflows/finance-daily/
├── SKILL.md       ← モデル向けの指示（散文）
├── fetch.mjs      ← 決定的な部分をスクリプトにしたもの（0 トークン）
└── verify.mjs     ← 検証。終了コード 0 で完了
```

`SKILL.md` の先頭にある小さな frontmatter ブロックは Fidere のスケジューラが読み、本文はモデルが読みます。

```markdown
---
name: finance-daily
description: 毎朝、金融ニュースを短いブリーフィングに要約します。
schedule: daily 08:00
budget: ¥0.4
verify: node verify.mjs
notify: echo "$FIDERE_TASK ok=$FIDERE_TASK_OK" >> notify.log   # any shell command
tools: read,write,bash
---

# 毎日の金融ブリーフィング

1. まず `node fetch.mjs` を実行します（自分で curl を書かないこと）。出力先: `out/raw.json`
2. `out/raw.json` を読み、指数を最も動かしそうな 5 件を選びます。
   単一企業の小さなニュースはスキップします。
3. `out/digest.md` を書きます。各項目 2 文、最後に「今日注目すべき点」のメモを加えます。
4. `node verify.mjs` を実行して自分の作業を確認します。

数字をでっち上げないこと。`raw.json` にないものはファイルに書きません。
```

三つの層がそれぞれ一つの役割を担います。**frontmatter はコード向け**（いつ・いくら・検証方法・通知先）、**本文はモデル向け**（どうするか・何が重要か・何をしないか）、**スクリプトはマシン向け**（決定的な作業）です。ドメインの内容は完全にあなた自身のディレクトリに置かれ、Fidere はそれについて何も仮定しません。

この形式は標準の [Agent Skills](https://agentskills.io/specification) なので、手元にあるスキルをそのまま `workflows/` に入れてスケジュールに載せることができ、書き直す必要はありません。

### 無人作業のための安全境界

チャット中はミスをその場で見られますが、誰も見ていないときはミスが一晩中走り続けます。だからこれは「行儀よくして」とプロンプトで頼む問題ではなく、ハードな境界で解決します。

- **実際の書き込み境界:** タスクが書き込めるのは自分専用の一時ディレクトリと `/tmp` だけです。`write`、`edit`、シェルのリダイレクトはそれ以外では拒否されます
- **危険な操作はツール層で遮断:** `sudo`、ルートからの削除、force push、外部ホストへのアップロード、`~/.pi/agent` の読み取りは拒否され `blocked.log` に記録されます
- **既定で無効な機能:** コマンド実行が不要なら `tools` から `bash` を外してください。タスクがあなたのスキル・拡張・プロジェクト指示を読み込むことはありません
- **すべてを記録:** セッション・コマンド・コスト・結果はすべて永続化され、実行を再現できます

これは境界であり、サンドボックスではありません。`bash` はそのアカウントが読めるものを読めます。本当の隔離にはコンテナか専用ユーザーが必要です。

Fidere は `127.0.0.1` のみをリッスンし、シングルユーザーで、アクセストークンを 1 つだけ受け付けます。これはあなた自身が（あるいは各自が自分用に）動かすためのもので、マルチテナントのプラットフォームではありません。

## クイックスタート

### 動作環境

- Node.js **22.19 以上**
- 対応プロバイダーの API キー（Anthropic、OpenAI、Google、DeepSeek、OpenRouter、Moonshot、MiniMax、xAI、Groq、Mistral など）
- macOS・Linux・Windows のいずれでも動きます。macOS 専用なのは 2 つだけ：任意のスリープ抑止（`npm run start:awake`）と、長いタスク中の `caffeinate` です。

### 1. クローンしてインストール

```bash
git clone https://github.com/sean-cc/fidere.git
cd fidere
npm install --ignore-scripts
npm run setup
```

`--ignore-scripts` は npm のライフサイクルスクリプトを飛ばすので、インストール時に何も実行されません（Fidere には不要です）。`npm run setup` でプロバイダーを選び API キーを入力すると、`~/.pi/agent/auth.json` に保存されます。**pi CLI を別途インストールする必要はありません**：通常の依存関係として入ります。

### 2. 起動

```bash
npm start
```

### 3. 開いてサインイン

<http://localhost:3000> を開き、起動時に表示されたアクセストークンを貼り付けます。トークンは `~/.pi/agent/fidere-token`（モード `0600`）にも保存されています。セッション Cookie の有効期間は 30 日です。

### 4. モデルを選ぶ

左下のモデル選択画面で選んでください。選ばない場合、保存済みの既定モデル、Fidere 独自の推奨（[FAQ](#よくある質問)参照）、最後に pi のプロバイダー別フォールバックの順で使います。

これで会話できます。`workflows/` に最初のワークフローを書いてもかまいません。

## インストールと設定

上のクイックスタートが推奨経路です。以下はすべて任意です。

### アップデート確認

起動のたびに、`npm start` は npm に新しい pi が公開されていないか確認します。対話的なターミナルでは更新するか尋ねられ、更新を選ぶとサーバー起動前にインストールされます。非対話環境では利用可能なバージョンを表示するだけで、通常どおり起動します。`FIDERE_SDK_UPDATE=off` で確認を省略でき、`auto` で確認なしに更新します。

### 代わりに環境変数を使う

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

`OPENAI_API_KEY`、`GEMINI_API_KEY`、`DEEPSEEK_API_KEY` など他のプロバイダーの環境変数も使えます。pi CLI は不要です。

### ポートとホスト

```bash
PORT=8080 npm start          # 既定は 3000
HOST=0.0.0.0 npm start       # 信頼できるネットワークのみ。下記参照
```

### アクセス制御

すべての API ルートにはアクセストークンが必要です。`FIDERE_TOKEN` から読むか、初回起動時に `~/.pi/agent/fidere-token` へ生成されます。初回は `/#token=<トークン>` を開くか、ログイン画面に貼り付けてサインインします。fragment はサーバーにもプロキシのログにも届きません。状態を変更するリクエストには、UI が自動で送る二重送信 CSRF トークンも必要です。[オプションの全一覧 →](docs/access-control.md)

サーバーは既定で `127.0.0.1` のみをリッスンします。インターネットに直接公開しないでください。TLS 付きのリバースプロキシか、プライベートなトンネルを使ってください。

## キーボードショートカット

| ショートカット | 動作 |
|----------|--------|
| `Enter` | メッセージを送信 |
| `Shift+Enter` | 入力欄で改行 |
| `/` | コマンドパレットを開く（コマンド、モデル、スキル、プロンプトテンプレート） |
| `↑` / `↓` | パレットの候補を移動 |
| `Tab` / `Enter` | 選択中の候補を決定 |
| `Esc` | コマンドパレットまたはセッション再開ダイアログを閉じる |
| `↑` / `↓`、`Home` / `End` | 右側のタイムラインにフォーカスがあるとき、以前のプロンプト間を移動 |

## よくある質問

- **価格はどこから来るのか？** 各モデルは**実際に呼ばれたエンドポイント**とベンダー自身の通貨で価格付けされます。DeepSeek 公式のピーク／オフピーク価格、OpenRouter 公式のトークン単価、Zhipu の人民元ページ、Anthropic・Moonshot・Aliyun・Hugging Face の公開価格ページ／API です。それ以外のエンドポイントは `models.json` で設定した `cost` を使い、pi 同梱の価格が最後のフォールバックです。詳細なルール・通貨の上書き・キャッシュは [docs/pricing.md](docs/pricing.md) を参照してください。
- **モデルが出てこない？** `npm run setup` を実行するか、プロバイダーの環境変数を設定してから、サーバーを再起動してください。
- **新しいセッションはどのモデルで始まるのか？** まず `~/.pi/agent/settings.json` の `defaultProvider`／`defaultModel`、次に Fidere 独自の推奨表（現在は DeepSeek → `deepseek-flash`）、最後に pi 内蔵のプロバイダー別テーブル、の順です。`npm run setup` は推奨モデルを settings に書き込み、モデルピッカーの各行にある **set default** で後から変更できます。この上書き層があるのは、pi のテーブルが DeepSeek を `deepseek-v4-pro` で開始するためです。これは `deepseek-flash` の 4.4 倍の入力価格で、テキストのみ対応であり、新規インストール直後に費用がかさむ予期せぬ事態になります。
- **蓋を閉じるとタスクは止まるのか？** サーバーはタスク実行中に `caffeinate` アサーションを保持できますが、蓋を閉じるとクラムシェルモードでない限りスリープします。本当の 24 時間 365 日稼働には、常時起動のマシンを使ってください。
- **キーはどこに保存されるのか？** `~/.pi/agent/auth.json` です。API キーがこのリポジトリに書き込まれることはありません。

## 開発

```bash
npm test          # ユニットテスト：価格、markdown、既定モデル、SDK チェック、スケジューラ
npm run smoke     # ヘッドレス Chrome の UI スモークテスト（Chrome/Chromium が必要）
npm run dev       # node --watch で起動
npm run daemon    # スケジューラを単体で実行（--list、--run <name>、--once）
```

アーキテクチャ、API エンドポイント、ローカライズ、pi のアップグレードに関する注意点は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

### コントリビュート

コントリビューションを歓迎します。以下を守ると PR が通りやすくなります。

1. バグ修正より大きな変更は、まず issue を立てて方針を合意してから書いてください。
2. 素のままに：フロントエンドフレームワーク、バンドラー、新しい実行時依存は、どうしても避けられない場合以外は追加しないでください。
3. push する前に `npm test` を実行し、UI に触れた場合は `npm run smoke` も実行してください。
4. PR には何を変え、どう検証したかを書いてください。スクリーンショット 1 枚かテスト名 1 つで十分です。

UI の文言は `public/i18n.js` にあり、7 言語すべてを揃える必要があります（揃っていないとスモークテストが落ちます）。
