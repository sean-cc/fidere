# Fidere

[![CI](https://github.com/sean-cc/fidere/actions/workflows/ci.yml/badge.svg)](https://github.com/sean-cc/fidere/actions/workflows/ci.yml)

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [繁體中文（香港）](README.zh-HK.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | **Русский**


Fidere — это небольшое рабочее пространство агента, работающее в браузере. Оно построено на SDK [pi coding agent](https://github.com/earendil-works/pi/tree/main/packages/coding-agent), поэтому агент умеет читать и записывать файлы, выполнять команды и в реальном времени транслировать свои размышления и вызовы инструментов — и при этом не тащит на вашу машину фреймворк, сборщик или второй сервис.

![Интерфейс диалога Fidere](docs/screenshot-chat.jpg)

- **Маленький намеренно** — одна зависимость (pi SDK), никакого фронтенд-фреймворка, сборщика и CDN. Около 8 300 строк чистого JS/CSS, а весь путь запуска — это `node scripts/start.mjs`.
- **Транслирует работу, а не только ответ** — размышления и вызовы инструментов появляются прямо в диалоге, сворачиваются по завершении ответа и раскрываются обратно для каждого ответа.
- **Говорит на вашем языке** — интерфейс доступен на English, 简体中文, 繁體中文 (Тайвань / Гонконг), 日本語, 한국어 и Русский; переключение — кнопкой с глобусом в боковой панели.
- **Показывает, сколько это стоит** — каждый ответ несёт расход токенов и цену самого поставщика для того эндпоинта, который реально использовался, а не статичный прайс-лист.
- **Никогда не выбирает дорогую модель за вашей спиной** — новые сессии начинаются с модели, которую видно и можно сменить, а тихая подмена модели при повторном открытии сессии объявляется над диалогом.

![Выбор модели с сохранённой моделью по умолчанию](docs/screenshot-models.jpg)

## Что вы можете делать

- Общаться с агентом в браузере и наблюдать за размышлениями и вызовами инструментов в реальном времени
- Сворачивать и раскрывать размышления и вызовы инструментов для каждого ответа; завершённые ответы сворачиваются автоматически
- Возвращаться к прежним запросам по хронологии справа
- Читать историю, не будучи утянутым вниз; вернуться к последнему выводу, когда будете готовы
- Управлять сессиями, переключать модели, прикреплять изображения и файлы
- Выбирать модель, с которой начинаются новые сессии (`set default` в списке моделей), и видеть уведомление, если при повторном открытии сессии модель пришлось сменить
- Видеть время, расход токенов и стоимость каждого ответа (цены поставщика с оценкой в юанях)
- Редактировать прежнее сообщение и отправить его заново в новой ветке, копировать ответы, повторять отклонённые запросы и восстанавливаться после обрыва потока
- Не давать Mac засыпать во время долгих задач (необязательно)
- Переключать язык интерфейса (English, 简体中文, 繁體中文 (Тайвань), 繁體中文 (Гонконг), 日本語, 한국어, Русский) кнопкой с глобусом в боковой панели

## Горячие клавиши

| Клавиши | Действие |
|----------|--------|
| `Enter` | Отправить сообщение |
| `Shift+Enter` | Перенести строку в поле ввода |
| `/` | Открыть палитру команд (команды, модели, навыки, шаблоны промптов) |
| `↑` / `↓` | Перемещение по результатам палитры |
| `Tab` / `Enter` | Принять выбранный пункт палитры |
| `Esc` | Закрыть палитру команд или диалог возобновления сессии |
| `↑` / `↓`, `Home` / `End` | Переход между прежними запросами, когда фокус на хронологии справа |

## Требования

- Node.js **22.19+**
- API-ключ поддерживаемого провайдера (Anthropic, OpenAI, Google, DeepSeek, OpenRouter, Moonshot, MiniMax, xAI, Groq, Mistral и другие)

## Установка и запуск

```bash
git clone https://github.com/sean-cc/fidere.git
cd fidere
npm install --ignore-scripts
npm run setup
npm start
```

Откройте <http://localhost:3000> и войдите с токеном доступа, напечатанным при запуске (он также хранится в `~/.pi/agent/fidere-token`). Сессионный cookie живёт 30 дней; полный список параметров — в разделе «Управление доступом» ниже.

При каждом запуске `npm start` спрашивает у npm, не опубликован ли более новый pi SDK. В интерактивном терминале он предложит обновиться; согласие устанавливает новый SDK перед запуском сервера. В неинтерактивном окружении он только печатает доступную версию и запускается как обычно. `FIDERE_SDK_UPDATE=off` отключает проверку, `FIDERE_SDK_UPDATE=auto` обновляет без вопроса.

`npm run setup` просит выбрать провайдера и ввести его API-ключ. Ему нужны только зависимости, установленные вместе с Fidere, — **устанавливать pi CLI не требуется**. Ключ сохраняется в `~/.pi/agent/auth.json`.

После запуска выберите модель в списке моделей в левом нижнем углу. Если не выбрать, Fidere использует сохранённую модель по умолчанию, затем собственную рекомендацию (см. ниже), затем резервную модель SDK для провайдера.

### Использовать переменную окружения

Если интерактивная настройка не нужна:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

`OPENAI_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY` и другие переменные окружения провайдеров тоже работают. pi CLI не требуется.

Другой порт:

```bash
PORT=8080 npm start
```

## Примечания

- **Цены:** Fidere оценивает каждую модель по тому эндпоинту, через который она реально вызывается. Модели на `api.deepseek.com` используют официальную страницу DeepSeek с пиковыми и непиковыми тарифами в соответствующей валюте (китайская страница/юани для локали `zh`, иначе английская страница/доллары; переопределяется через `FIDERE_PRICE_CURRENCY=CNY|USD`); модели на `openrouter.ai` используют официальную цену за токен от OpenRouter; модели на `open.bigmodel.cn` используют официальную документацию по тарифам Zhipu (юани); модели на `api.anthropic.com`, `api.moonshot.cn`, `dashscope.aliyuncs.com` и `router.huggingface.co` также используют свои официальные страницы цен или API. Все остальные эндпоинты используют `cost`, заданный вами для этого провайдера в `models.json` (прокси и шлюзы сохраняют свою цену), а встроенная цена SDK применяется как последний резерв. Цены сохраняют валюту поставщика (юани для DeepSeek в локали `zh`, GLM, Moonshot и Aliyun; доллары для OpenRouter, Anthropic, HuggingFace и DeepSeek вне локали `zh`); подсказка с юанями для долларовых цен — оценка по курсу 7,2 юаня за доллар (`localStorage.setItem('fidere-usd-cny', '7.30')`). Проверки начинаются при старте сервера; неудачные проверки сохраняют предыдущий кеш, модели, отсутствующие в последнем списке поставщика, сохраняют свою последнюю официальную цену, и только если нет ни того, ни другого, применяется цена SDK. Кеш находится в `~/.pi/agent/fidere-prices.json`; `FIDERE_PRICES=off` отключает обращение к поставщикам. Статус: `GET /api/prices`.
- **Нет моделей?** Запустите `npm run setup` или задайте переменную окружения провайдера, затем перезапустите сервер.
- **С какой модели начинаются новые сессии?** Сначала `defaultProvider`/`defaultModel` из `~/.pi/agent/settings.json`, затем собственная таблица рекомендаций Fidere (сейчас только DeepSeek → `deepseek-flash`), затем встроенная таблица SDK по провайдерам. `npm run setup` записывает рекомендованную модель в settings, а **set default** в любой строке списка моделей меняет её позже; значок **default** отмечает то, что будут использовать новые сессии. Это переопределение существует потому, что таблица SDK запускает DeepSeek на `deepseek-v4-pro` — в 4,4 раза дороже по входу, чем `deepseek-flash`, и без поддержки изображений, — что оборачивается дорогим сюрпризом сразу после установки.
- **Управление доступом:** каждый API-маршрут требует токен доступа. Он читается из `FIDERE_TOKEN` или генерируется при первом запуске в `~/.pi/agent/fidere-token` (права 0600); путь печатается при старте. Войдите один раз, открыв `/#token=<токен>` или вставив его в форму входа — фрагмент никогда не попадает ни на сервер, ни в лог прокси. Сессионный cookie помечен `HttpOnly`, `SameSite=Strict` и живёт 30 дней (`FIDERE_SESSION_MAX_AGE`, в секундах). Запросы, меняющие состояние, также требуют CSRF-токен с двойной отправкой, который UI присылает автоматически; скрипты могут вместо этого слать `Authorization: Bearer <токен>`. `FIDERE_COOKIE_SECURE=auto|on|off` управляет флагом `Secure` (по умолчанию — следовать `X-Forwarded-Proto`). `FIDERE_AUTH=off` отключает всё это — только для машины, до которой больше никто не достанет.
- **Доступ с другого компьютера:** по умолчанию сервер слушает только `127.0.0.1`. Не выставляйте его напрямую в интернет. Используйте обратный прокси с TLS или приватный туннель. `HOST=0.0.0.0` подходит только для доверенных сетей.
- **Сон Mac:** сервер может удерживать `caffeinate`-ассерт во время активных задач. Закрытие крышки всё равно усыпит машину, если только Mac не в режиме закрытой крышки; для длительных задач без присмотра используйте постоянно включённую машину.
- **Где хранятся ключи?** `~/.pi/agent/auth.json`. API-ключи никогда не попадают в этот репозиторий.
