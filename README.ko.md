**항상 켜져 있는 어시스턴트. 자리를 비운 동안에도 일정대로 일을 끝내고, 결과를 책임 있게 보고합니다.**

Fidere는 항상 켜져 있는 어시스턴트입니다. 브라우저에서 대화하고, 질문하고, 떠오른 아이디어를 흘려보내 잃어버리지 않게 맡겨둘 수 있습니다. 여러분이 자리를 비우면 일정에 따라 스스로 작업합니다——감독 없이도 끝까지 수행하고, 결과를 알려 주며, 작업이 예산을 초과하면 스스로 멈춥니다.

Fidere는 라틴어로 **"신뢰하다"** 라는 뜻입니다. 신뢰는 더 똑똑한 모델에서 오는 것이 아니라, 세 가지 평범한 사실에서 옵니다. **한 일은 검증할 수 있고, 망친 것은 되돌릴 수 있으며, 쓴 돈은 장부에 남습니다**.

![Fidere 대화 화면](docs/screenshot-chat.jpg)

> **처음이신가요?** [빠른 시작](#빠른-시작)으로 바로 가세요. 클론에서 실행까지 약 5분이면 됩니다.

## 무엇이 다른가

### 스스로 읽을 수 있을 만큼 작다

의존성은 하나뿐입니다: [pi coding agent](https://github.com/earendil-works/pi). Fidere는 이를 라이브러리로 쓰기 때문에 `pi` CLI를 직접 설치할 필요가 없습니다. 프런트엔드 프레임워크도, 번들러도, CDN도 없고, 약 8,300줄의 순수 JS/CSS로 이루어져 있습니다. 데이터베이스도, 메시지 큐도, 두 번째 서비스도 없습니다. `node scripts/start.mjs`가 실행 경로의 전부입니다. 워크플로는 새로 배워야 할 언어가 아니라, 여러분이 소유한 디렉터리 안의 몇 개 파일일 뿐입니다.

### 같은 기록에 두 번 돈을 내지 않습니다

대부분의 자동화 어시스턴트는 끝나지 않는 하나의 세션으로, 매 턴마다 전체 기록을 모델에 다시 보냅니다. 그래서 오래 돌릴수록 느려지고 비싸집니다. Fidere는 그 반대입니다.

- **작업마다 세션을 하나씩 쓰고, 끝나면 버립니다.** 작업 간에는 전체 대화록이 아니라 수백 단어 요약만 넘겨받습니다.
- **판단이 필요 없는 단계는 모델에 도달하지 않습니다.** 가져오기, 변환, 검증, 알림은 모두 스크립트라 0 토큰입니다.
- **저렴한 모델이 판단하고, 비싼 모델이 실행합니다.** 라우팅, 요약, 서식 지정은 가벼운 모델에서 돌고, 어려운 작업만 상위 모델로 올라갑니다.
- **모든 작업에는 예산 상한이 있습니다.** 초과하면 작업이 멈추고, 어디까지 했는지와 얼마를 썼는지가 장부에 기록됩니다.

### "완료"는 모델이 스스로 말할 수 있는 것이 아닙니다

모든 작업에는 실행 가능한 검증이 있습니다. 종료 코드가 0이 아니면 완료되지 않은 것입니다. 실패는 세 단계로 확대됩니다. 같은 모델에서 한 번 재시도 → 더 강한 모델에서 한 번 재시도 → 여러분에게 알리고 중지. 아침까지 조용히 갈아대지 않습니다. 재실행은 부작용을 중복시키지 않습니다(알림 두 번, 주문 두 번 없음). 각 작업의 세션, 명령, 비용, 결과가 모두 보존되므로, 실패한 실행은 추측하는 대신 다시 재생할 수 있습니다.

### 비용은 실제 엔드포인트에서 나옵니다

모든 응답에는 토큰 사용량과 **실제로 호출한 엔드포인트**의 공급자 공식 가격이 함께 표시됩니다. DeepSeek의 피크/오프피크 요금, OpenRouter의 토큰당 가격, Zhipu·Moonshot·Aliyun·Anthropic의 공개 페이지 등——고정된 요금표가 아닙니다. 프록시와 자체 게이트웨이는 여러분이 설정한 `cost`로 계산합니다. [엔드포인트별 가격 규칙 →](docs/pricing.md)

### 비싼 모델을 몰래 바꿔치기하지 않습니다

새 세션은 여러분이 보고 바꿀 수 있는 모델에서 시작합니다. 다시 연 세션에서 모델을 바꿔야 했다면 대화록 위에 공지됩니다. 대체 모델은 몇 배 더 비쌀 수 있는데, 그런 사실을 로그 파일에만 남겨 두지 않습니다.

## 기능

### 대화: 마음에 떠오르는 것을 아무거나 말하세요

- **끊기지 않는 세션** —— 계속 대화할 수 있습니다. 컨텍스트가 차면 자동으로 요약되어 어디까지 했는지 잊지 않습니다.
- **열어볼 수 있는 노트** —— 아이디어, 결론, 할 일을 열고 편집하고 검색할 수 있는 markdown으로 기록합니다. 블랙박스가 아닙니다.
- **실시간 스트리밍** —— 사고 과정과 도구 호출이 실시간으로 흐르고, 응답이 끝나면 접히며, 응답별로 다시 펼칠 수 있습니다.
- **타임라인 이동** —— 오른쪽 타임라인을 클릭 한 번으로 이전 프롬프트로 돌아갑니다. 기록을 읽는 동안 화면이 아래로 끌려가지 않습니다.
- **분기 재전송과 복구** —— 이전 메시지를 편집해 새 분기로 다시 보냅니다. 응답 복사, 거부된 프롬프트 재시도, 끊긴 스트림 복구도 가능합니다.
- **세션과 모델 관리** —— 세션 관리, 모델 전환, 새 세션의 기본 모델 지정, 이미지와 파일 첨부.
- **7개 UI 언어** —— English, 简体中文, 繁體中文(台灣/香港), 日本語, 한국어, Русский.
- **명령 팔레트** —— `/` 하나로 명령, 모델, 스킬, 프롬프트 템플릿을 검색합니다([단축키](#키보드-단축키)).
- **Mac 잠들지 않게** —— 긴 작업 동안 선택적으로 `caffeinate`를 유지합니다.

### 작업: 여러분이 자리를 비운 동안 처리합니다

- **일정 실행** —— N분마다, 매일 특정 시각, 또는 평일에만.
- **하드 예산** —— 조용히 비용을 태우는 대신 멈춥니다.
- **실행 가능한 검증** —— 모델의 "완료"는 단서일 뿐이고, 종료 코드가 결론입니다.
- **확대와 알림** —— 같은 모델 → 더 강한 모델 → 알리고 중지.
- **발화 시각마다 한 번만** —— 안정적인 `FIDERE_RUN_KEY`도 함께 주어, 외부 부작용(주문, 발송)을 스스로 중복 제거할 수 있습니다.
- **장부와 일일 영수증** —— 무엇이 실행됐고, 무엇이 통과했고, 얼마가 들었는지.
- **놓친 작업 보충** —— 재시작이나 슬립 후 놓친 작업을 보충하고, 영수증에 얼마나 늦었는지 적습니다.

### 워크플로: 설명 한 페이지와 스크립트 몇 개

순서도도, 새로운 문법도, 오케스트레이션 엔진도 필요 없습니다. 워크플로는 하나의 디렉터리입니다.

```text
workflows/finance-daily/
├── SKILL.md       ← 모델을 위한 지시문(산문)
├── fetch.mjs      ← 결정적인 부분을 스크립트로: 0 토큰
└── verify.mjs     ← 검증. 종료 코드 0이면 완료
```

`SKILL.md` 맨 위의 작은 frontmatter 블록은 Fidere의 스케줄러가 읽고, 본문은 모델이 읽습니다.

```markdown
---
name: finance-daily
description: 매일 아침 금융 뉴스를 짧은 브리핑으로 요약합니다.
schedule: daily 08:00
budget: ¥0.4
verify: node verify.mjs
notify: echo "$FIDERE_TASK ok=$FIDERE_TASK_OK" >> notify.log   # any shell command
tools: read,write,bash
---

# 매일 금융 브리핑

1. 먼저 `node fetch.mjs`를 실행합니다(직접 curl을 쓰지 마세요). 출력: `out/raw.json`
2. `out/raw.json`을 읽고 지수를 가장 움직일 만한 5건을 고릅니다.
   단일 기업의 작은 뉴스는 건너뜁니다.
3. `out/digest.md`를 씁니다. 항목당 두 문장, 마지막에 "오늘 지켜볼 것" 메모를 붙입니다.
4. `node verify.mjs`를 실행해 스스로 검증합니다.

숫자를 지어내지 마세요. `raw.json`에 없으면 파일에도 쓰지 않습니다.
```

세 개의 층이 각각 한 가지 일을 맡습니다. **frontmatter는 코드를 위해**(언제, 얼마나, 어떻게 검증하고, 누구에게 알릴지), **본문은 모델을 위해**(어떻게, 무엇이 중요한지, 무엇을 하지 말지), **스크립트는 기계를 위해**(결정적인 작업). 도메인 내용은 전부 여러분의 디렉터리에 있고, Fidere는 그것에 대해 아무것도 가정하지 않습니다.

형식은 표준 [Agent Skills](https://agentskills.io/specification)이므로, 이미 가진 스킬을 `workflows/`에 넣어 일정에 올릴 수 있고 다시 작성할 필요가 없습니다.

### 무인 작업을 위한 안전 경계

대화 중에는 실수를 그 자리에서 볼 수 있지만, 아무도 보지 않을 때는 실수가 밤새 돌아갑니다. 그래서 이 문제는 "얌전히 굴어라"고 프롬프트로 부탁해서 풀지 않고, 단단한 경계로 풉니다.

- **실제 쓰기 경계:** 작업은 자신의 일회용 디렉터리와 `/tmp`에만 쓸 수 있습니다. `write`, `edit`, 셸 리다이렉션은 그 밖에서 모두 거부됩니다
- **위험한 동작은 도구 계층에서 차단:** `sudo`, 루트 삭제, force push, 외부 호스트 업로드, `~/.pi/agent` 읽기는 거부되고 `blocked.log`에 기록됩니다
- **기본값은 꺼짐:** 명령 실행이 필요 없으면 `tools`에서 `bash`를 빼세요. 작업은 당신의 스킬, 확장, 프로젝트 지시를 불러오지 않습니다
- **모두 기록:** 세션, 명령, 비용, 결과가 모두 저장되어 실행을 재생할 수 있습니다

이것은 경계이지 샌드박스가 아닙니다. `bash`는 해당 계정이 읽을 수 있는 파일을 여전히 읽을 수 있습니다. 진짜 격리에는 컨테이너나 전용 사용자가 필요합니다.

Fidere는 `127.0.0.1`만 수신하고, 단일 사용자이며, 액세스 토큰 하나만 받습니다. 여러분 자신이(또는 각자가 자기용으로) 돌리는 것이지, 멀티테넌트 플랫폼이 아닙니다.

## 빠른 시작

### 요구 사항

- Node.js **22.19+**
- 지원되는 공급자의 API 키(Anthropic, OpenAI, Google, DeepSeek, OpenRouter, Moonshot, MiniMax, xAI, Groq, Mistral 등)
- macOS, Linux, Windows 모두 됩니다. macOS 전용은 두 가지뿐입니다: 선택적 슬립 방지(`npm run start:awake`)와 긴 작업 중의 `caffeinate`.

### 1. 클론 및 설치

```bash
git clone https://github.com/sean-cc/fidere.git
cd fidere
npm install --ignore-scripts
npm run setup
```

`--ignore-scripts`는 npm 라이프사이클 스크립트를 건너뛰므로 설치 시 아무것도 실행되지 않습니다(Fidere에는 필요 없습니다). `npm run setup`은 공급자를 고르고 API 키를 입력받아 `~/.pi/agent/auth.json`에 저장합니다. **pi CLI를 따로 설치할 필요는 없습니다**: 일반 의존성으로 함께 설치됩니다.

### 2. 서버 시작

```bash
npm start
```

### 3. 열고 로그인

<http://localhost:3000>을 열고 시작할 때 출력된 액세스 토큰을 붙여넣습니다. 토큰은 `~/.pi/agent/fidere-token`(모드 `0600`)에도 저장됩니다. 세션 쿠키는 30일 동안 유지됩니다.

### 4. 모델 선택

왼쪽 아래 모델 선택기에서 하나를 고릅니다. 고르지 않으면 저장된 기본값, Fidere 자체 추천([FAQ](#자주-묻는-질문) 참고), 그다음 pi의 공급자별 폴백 순으로 사용합니다.

이제 대화할 수 있습니다. `workflows/` 아래에 첫 워크플로를 작성해도 됩니다.

## 설치 및 설정

위의 빠른 시작이 권장 경로입니다. 나머지는 모두 선택 사항입니다.

### 업데이트 확인

시작할 때마다 `npm start`는 npm에 더 새로운 pi가 게시되었는지 확인합니다. 대화형 터미널에서는 업데이트할지 묻고, yes를 선택하면 서버를 시작하기 전에 설치합니다. 비대화형 환경에서는 사용 가능한 버전만 출력하고 평소대로 시작합니다. `FIDERE_SDK_UPDATE=off`로 확인을 건너뛰거나, `auto`로 묻지 않고 업데이트할 수 있습니다.

### 대신 환경 변수 사용

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

`OPENAI_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`와 다른 공급자 환경 변수도 동작합니다. pi CLI는 필요 없습니다.

### 포트와 호스트

```bash
PORT=8080 npm start          # 기본값 3000
HOST=0.0.0.0 npm start       # 신뢰할 수 있는 네트워크에서만. 아래 참고
```

### 액세스 제어

모든 API 경로에는 액세스 토큰이 필요합니다. `FIDERE_TOKEN`에서 읽거나, 첫 시작 시 `~/.pi/agent/fidere-token`에 생성됩니다. `/#token=<토큰>`을 열거나 로그인 오버레이에 붙여넣어 한 번 로그인하면 됩니다. fragment는 서버나 프록시 로그에 전달되지 않습니다. 상태를 변경하는 요청에는 UI가 자동으로 보내는 이중 제출 CSRF 토큰도 필요합니다. [전체 옵션 →](docs/access-control.md)

서버는 기본적으로 `127.0.0.1`에서만 수신합니다. 인터넷에 직접 노출하지 마세요. TLS가 적용된 리버스 프록시나 사설 터널을 사용하세요.

## 키보드 단축키

| 단축키 | 동작 |
|--------|------|
| `Enter` | 메시지 보내기 |
| `Shift+Enter` | 입력창에서 줄바꿈 |
| `/` | 명령 팔레트 열기(명령, 모델, 스킬, 프롬프트 템플릿) |
| `↑` / `↓` | 팔레트 결과 사이 이동 |
| `Tab` / `Enter` | 선택한 팔레트 항목 확정 |
| `Esc` | 명령 팔레트 또는 세션 이어하기 대화상자 닫기 |
| `↑` / `↓`, `Home` / `End` | 오른쪽 타임라인에 포커스가 있을 때 이전 프롬프트 사이 이동 |

## 자주 묻는 질문

- **가격은 어디서 오나요?** 각 모델은 **실제로 호출된 엔드포인트**와 공급자 자체 통화로 가격이 정해집니다. DeepSeek 공식 피크/오프피크 요금, OpenRouter 공식 토큰당 가격, Zhipu의 위안화 페이지, Anthropic·Moonshot·Aliyun·Hugging Face의 공개 가격 페이지/API입니다. 그 밖의 엔드포인트는 `models.json`에서 설정한 `cost`를 쓰고, pi에 포함된 가격이 마지막 폴백입니다. 자세한 규칙, 통화 재정의, 캐시는 [docs/pricing.md](docs/pricing.md)를 참고하세요.
- **모델이 없나요?** `npm run setup`을 실행하거나 공급자 환경 변수를 설정한 뒤 서버를 다시 시작하세요.
- **새 세션은 어떤 모델로 시작하나요?** 먼저 `~/.pi/agent/settings.json`의 `defaultProvider`/`defaultModel`, 그다음 Fidere 자체 추천 표(현재 DeepSeek → `deepseek-flash`), 마지막으로 pi 내장 공급자별 표 순입니다. `npm run setup`은 추천 모델을 settings에 기록하고, 모델 선택기 행의 **set default**로 나중에 바꿀 수 있습니다. 이 재정의가 있는 이유는 pi의 표가 DeepSeek을 `deepseek-v4-pro`로 시작하기 때문입니다. 이 모델은 `deepseek-flash` 입력 가격의 4.4배이고 텍스트 전용이라, 새로 설치한 사용자에게 비용이 많이 드는 놀라움이 됩니다.
- **덮개를 닫으면 작업이 멈추나요?** 서버는 활성 작업 중에 `caffeinate` 어서션을 유지할 수 있지만, Mac이 클램셸 모드가 아닌 한 덮개를 닫으면 잠듭니다. 진짜 24/7 작업에는 항상 켜져 있는 머신을 사용하세요.
- **키는 어디에 저장되나요?** `~/.pi/agent/auth.json`입니다. API 키는 이 저장소에 기록되지 않습니다.

## 개발

```bash
npm test          # 단위 테스트: 가격, markdown, 기본 모델, SDK 확인, 스케줄러
npm run smoke     # 헤드리스 Chrome UI 스모크 테스트(Chrome/Chromium 필요)
npm run dev       # node --watch로 시작
npm run daemon    # 스케줄러만 실행(--list, --run <name>, --once)
```

아키텍처, API 엔드포인트, 로컬라이제이션, pi 업그레이드 참고 사항은 [DEVELOPMENT.md](DEVELOPMENT.md)를 참고하세요.

### 기여하기

기여를 환영합니다. 다음을 지키면 PR이 훨씬 잘 병합됩니다.

1. 버그 수정보다 큰 변경은 먼저 issue를 열어 방향을 합의한 뒤 작성하세요.
2. 소박하게 유지하세요: 프런트엔드 프레임워크, 번들러, 새 런타임 의존성은 정말 피할 수 없을 때만 추가합니다.
3. push 전에 `npm test`를 실행하고, UI를 건드렸다면 `npm run smoke`도 실행하세요.
4. PR에 무엇을 바꿨고 어떻게 검증했는지 적으세요. 스크린샷 하나나 테스트 이름 하나면 충분합니다.

UI 문구는 `public/i18n.js`에 있으며, 7개 언어를 모두 채워야 합니다(아니면 스모크 테스트가 실패합니다).
